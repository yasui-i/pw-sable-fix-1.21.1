# 1.5.1 依赖与安装

本表依据本地实际 JAR 的 `neoforge.mods.toml`、内置库清单和本轮隔离测试整理。只用于 Minecraft **1.21.1 NeoForge / Java 21**，不是 Fabric 或 Forge 版。

| 组件 | 正式版要求 | 本地编译、测试使用 |
| --- | --- | --- |
| Minecraft | 1.21.1 | 1.21.1 |
| Java | 21 | OpenJDK 21 |
| NeoForge | 21.1.242 及以上的 21.1.x | 21.1.242 |
| Create | 6.0.10 至 6.1.0 之前 | 6.0.10 |
| Pantographs & Wires | **1.21.1-beta-0.2.3-C6** | 同左 |
| Sable | **2.0.6** | 同左 |
| Create Electro Energetics | **1.21.1-1.2.0-127** | 同左 |
| DragonLib | 3.0.29 至 3.1.0 之前 | 3.0.29 |
| GeckoLib | 4.8.4 至 5.0.0 之前，由P&W内置 | P&W内置4.8.4，无独立JAR |

P&W、Sable、CEE 的关键接口使用精确版本约束，避免未验证的内部接口变更造成启动崩溃。其他允许范围不表示逐一验证过所有版本；排查时请优先使用表中测试组合。NeoForge 21.1.258 属于允许范围，本轮服务端回归使用 21.1.242。

## 哪些库不用额外下载

- Sable 2.0.6 内置 **Sable Companion 1.6.0、Rapier 2.0.6、Veil 4.3.2**。
- Create 6.0.10 内置 **Flywheel 1.0.6、Ponder 1.0.82、Registrate**。
- DragonLib 3.0.29 内置 **Architectury 13.0.6、Forge Config API Port 21.1.1**。
- P&W 内置 **GeckoLib 4.8.4**，满足本版要求，**无需单独安装或下载GeckoLib**。1.5.0中要求4.9.3的限制已在1.5.1修正。
- CEE 也内置 Sable Companion 1.6.0；正常由加载器解析，无需手动提取再放进 `mods/`。

## 安装

1. 准备 Minecraft 1.21.1 / NeoForge 实例和 Java 21。
2. 安装 Create、P&W、Sable、CEE、DragonLib，优先使用表中的测试版本。GeckoLib使用P&W内置版本，不需另装。
3. 在客户端及服务端的 `mods/` 中加入 **`pwsablefix-1.5.1.jar`**。
4. 移出旧版 `pwsablefix-*.jar`，不要同时加载多个版本。`modId` 保持 `pwsablefix`，原有配置和受电弓登记字段保持兼容。
5. 若已有旧的、重复修改 P&W 受电弓的 `createsimurailadditions-1.1.1.jar` 兼容补丁，应移出；这与模组 ID 为 `simurail` 的物理转向架本体不是同一概念。

**EMU Cab、Simurail、DriveByWire、DriveBySable 都不是本附属的必装依赖。** 只有需要驾驶台联动、转向架或线缆控制时才按各自说明安装。

## 配置与使用

启动后生成 `config/pwsablefix-common.toml`，默认启用红石升降弓、Sable 物理结构接触检测和 CEE 电路桥接。供电需要完整回路；已登记到驾驶台的受电弓需合上 VCB。未登记受电弓可独立使用。

多腕臂旧公共端子接线映射到腕臂1，其他腕臂需分别接线。绝缘子仅切断该位置的连续导电，不会移除其他电源或旁路。
