# P&W Sable Fix 1.5.2 — CEE 1.1.4

## English

- Rebuilt against the public CEE release `1.21.1-1.1.4` and corrected the dependency requirement.
- Updated compiled circuit-node calls to the return types used by CEE 1.1.4. This prevents method-linkage errors caused by the previous development build.
- Preserves redstone pantograph control, real P&W wire conduction, independent cantilever terminals, section insulation, moving arc sounds and cab telemetry.
- Updated installation instructions and dependency checksums.

Tested with Minecraft 1.21.1, NeoForge 21.1.242, Create 6.0.10, P&W 1.21.1-beta-0.2.3-C6, Sable 2.0.6, CEE 1.21.1-1.1.4 and DragonLib 3.0.29. Packaged-JAR server checks passed: 75 multiarm assertions, 136 moving DC assertions and 136 moving AC assertions. Existing game assets and logo are byte-for-byte unchanged.

Replace the previous addon with `pwsablefix-1.5.2.jar` on client and server. Use CEE `electroenergetics-1.21.1-1.1.4.jar`.

## 中文

- 改用 CEE 公开发布版 `1.21.1-1.1.4` 编译，并修正依赖版本声明。
- 重新生成适配 CEE 1.1.4 返回类型的电路节点调用，避免旧开发版接口造成运行时方法缺失。
- 保留红石升降弓、P&W 线网导电、多腕臂独立端子、绝缘分段、随车电弧音效和驾驶台遥测。
- 更新安装文档、模组介绍及依赖校验信息。

已用实际发行 JAR 通过隔离服务端测试：多腕臂 75 项、移动直流 136 项、移动交流 136 项。游戏资源和 Logo 与 1.5.1 逐字节一致。

客户端和服务端用 `pwsablefix-1.5.2.jar` 替换旧版，CEE 使用 `electroenergetics-1.21.1-1.1.4.jar`。

本轮未人工进入客户端实驾、试听或检查动画；服务端测试不代替完整整合包验证。
