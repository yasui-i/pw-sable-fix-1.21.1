# P&W Sable Fix 1.5.0 — 首个公开正式版

> 历史版本：1.5.0误将GeckoLib最低版本设为4.9.3。请安装1.5.1或更新版，直接使用P&W内置4.8.4，无需单独安装GeckoLib。以下为原发布记录。

Minecraft 1.21.1 · NeoForge · Java 21

连接 P&W 的铁路设施、Sable 的移动物理结构与 CEE 的电力系统，让物理列车可以通过受电弓从接触网实际取电。

## 本版内容

- 红石有信号升弓、无信号降弓，支持 P&W 与原生 CEE 受电弓。
- Sable 物理结构上的 P&W 受电弓接触检测、P&W 接触线与馈线真实导电。
- 多腕臂独立电气端子与线缆绝缘分段。
- 接触/脱离带电线网的随车电弧音效。
- 可选 EMU Cab 受电弓登记、VCB、实际网压与网流反馈。
- 延续1.4.5移动换线段时的电气遥测同步修复；添加用户提供的Logo及完整安装文档。

这是首个GitHub正式发行版本，版本号为1.5.0，保持 `pwsablefix` 模组ID。与开发版1.4.5相比，游戏功能类未改动，发行物仅更新元数据、依赖约束及Logo，不撤销已有功能。

## 必需前置

推荐使用本轮测试组合：

| 组件 | 版本 |
| --- | --- |
| Minecraft | 1.21.1 |
| NeoForge | 21.1.242及以上21.1.x（本轮测试21.1.242） |
| Create | 6.0.10 |
| Pantographs & Wires | 1.21.1-beta-0.2.3-C6 |
| Sable | 2.0.6 |
| Create Electro Energetics | 1.21.1-1.2.0-127 |
| DragonLib | 3.0.29 |
| GeckoLib | 4.9.3 |

P&W、Sable、CEE采用精确版本约束。Sable Companion、Veil、Flywheel、Ponder、Architectury等由前置内置，无需重复安装。GeckoLib需另装4.9.3，P&W内置的4.8.4不满足本正式版要求。完整范围见 [依赖与安装](https://github.com/yasui-i/pw-sable-fix-1.21.1/blob/main/docs/依赖与安装.md)。

EMU Cab、Simurail及线缆控制不是本附属的必装依赖。驾驶台联动按需安装EMU Cab；独立渐变电机与转向架VVVF属于EMU Cab。

## 安装与升级

客户端、服务端均放入 `pwsablefix-1.5.0.jar`，移出旧版 `pwsablefix-*.jar`。原配置与受电弓登记字段保留。供电须有带电接触网、负载及闭合回路；登记到驾驶台后须合VCB。多腕臂旧公共端子接线归腕臂1，其他腕臂需分别接线。

发布附件中的JAR可直接安装；源码ZIP用于开发，文档ZIP为介绍与安装说明，不包含第三方依赖模组。校验文件见 `SHA256SUMS.txt`。

## 验证范围

本轮使用打包后的正式JAR运行隔离服务端，检查最小前置组合、多腕臂接线与绝缘分段、移动物理体跨接触网段的直流和交流供电。触网音效状态检查及完整构建通过。未重新进行完整玩家线路实驾、客户端Logo界面及音效人工试听；当前版本不宣称已验证所有允许范围内的前置版本。

项目为独立兼容附属。Logo由项目作者提供，组合图标归对应模组作者；游戏电弧音效直接引用已安装CEE，不捆绑其音频或其他前置JAR。
