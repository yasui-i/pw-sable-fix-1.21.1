# P&W Sable Fix 1.5.1 — 使用P&W内置GeckoLib

修正1.5.0中误设的GeckoLib 4.9.3最低版本限制，改为接受P&W自带的4.8.4。**玩家无需单独下载或安装GeckoLib。**

本轮编译使用从P&W原JAR提取的GeckoLib 4.8.4；隔离服务端不放独立GeckoLib JAR，由P&W内置库提供运行依赖。验证多腕臂独立供电、绝缘分段及移动物理结构上的直流/交流取电。

Minecraft 1.21.1、Java21、NeoForge21.1.242及以上的21.1.x。推荐组合：Create6.0.10、P&W1.21.1-beta-0.2.3-C6、Sable2.0.6、CEE1.21.1-1.2.0-127、DragonLib3.0.29。其他前置及内置库规则保持不变，详见[依赖与安装](https://github.com/yasui-i/pw-sable-fix-1.21.1/blob/main/docs/依赖与安装.md)。

客户端和服务端均用 `pwsablefix-1.5.1.jar` 替换旧版附属，不要同时保留1.5.0。原Logo、功能代码、配置和登记数据保持不变。若此前仅为1.5.0添加了独立GeckoLib，现在不再需要；其他模组有自己的版本要求时仍须遵循其依赖规则。

验证不包含本轮完整玩家线路实驾或客户端动画人工检查。校验文件见附件 `SHA256SUMS.txt`。发行物不捆绑GeckoLib或其他第三方模组。
