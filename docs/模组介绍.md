# P&W Sable Fix

让接触网真正为你的物理列车供电。

P&W Sable Fix 是面向 Minecraft 1.21.1 NeoForge 的铁路电气兼容附属，将 **Pantographs & Wires 的接触网与受电弓、Sable 的移动物理结构，以及 Create Electro Energetics 的电路系统**连接起来。它保留 P&W 的铁路设施外观，让供电、接触和控制也参与列车运行。

## 主要功能

- **红石升降弓**：P&W 和原生 CEE 受电弓收到红石信号时升起，信号消失后收起，适合与列车控制线路连接。
- **移动结构取电**：P&W 受电弓安装在 Sable 物理列车上时，会按车体位置与朝向检测接触网，支持从 P&W 导线或 CEE 支持的线网取电。
- **P&W 导线真实导电**：接触线与馈线接入 CEE 电路，可将地面的电源送到车载负载。网压与网流来自 CEE 求解结果，而非固定的装饰数值。
- **多腕臂独立供电**：同一安装座上的多个腕臂拥有各自的电气端子，可以分别接入电源。端子横向排列，按腕臂顺序选择，不会因为共用支柱就自动串电。
- **绝缘子分段**：P&W 导线上的绝缘子可切断线段两侧的电气连续性，支持制作分段供电线路。另一侧若有独立电源或旁路，仍可能带电。
- **随车触网音效**：受电弓与带电接触网接触、分离时播放不同长度的电弧声，声音跟随物理结构移动；连续换线段和动画回弹不会反复触发。
- **驾驶台联动**：搭配 EMU Cab，可登记 03/06 车受电弓，通过主断路器指令控制真实供电，并读取网压与取流。

## 如何开始

在客户端和服务端安装本附属及所需前置。使用 CEE 线轴把电源接入 P&W 接线器或腕臂端子，再通过 P&W 馈线、接触线构成供电线路。将车上受电弓端子与 CEE 用电设备、回流线路连接成闭合回路，施加红石信号升弓，即可测试接触取电。

升弓不等于通电：接触网必须已有电源，负载需要正确接线。没有接触网也可以机械升弓；没有有效负载时，电流可能为零。已登记到驾驶台的受电弓还需合上 VCB 主断。

## 版本与安装

当前正式版为 **1.5.1**，延续首个正式版1.5.0的功能，并修正GeckoLib版本限制，直接使用P&W内置4.8.4，无需另装。Minecraft 1.21.1、Java 21，客户端与服务端使用同一版本。前置清单及已验证版本见 [依赖与安装说明](依赖与安装.md)。

该附属不要求安装 EMU Cab、Simurail 或线缆控制模组；驾驶台联动按需搭配。独立渐变电机和转向架 VVVF 音效由 EMU Cab 提供，不属于本附属的独立内容。
