# P&W Sable Fix 1.5.2

**Power your moving physics train through real overhead wires.**

A railway electrical compatibility addon for **Minecraft 1.21.1 NeoForge**, connecting Pantographs & Wires, Sable and Create Electro Energetics.

## Features

- Raise P&W and CEE pantographs with redstone; lower them when the signal disappears.
- Collect power from P&W or CEE overhead wires on moving Sable structures.
- Connect P&W contact wires and feeders to the CEE electrical simulation and supply onboard loads.
- Feed multiple cantilever arms independently through horizontally arranged terminals, with wire insulators for section isolation.
- Play moving electrical arc sounds when a collector makes or breaks contact with energized wires.
- Link with EMU Cab for pantograph registration, VCB control and actual voltage/current readings.

## Installation

Install `pwsablefix-1.5.2.jar` on both client and server. Requires Java 21.

| --- | --- |
| Minecraft | 1.21.1 |
| NeoForge | 21.1.242 |
| Create | 6.0.10 |
| Pantographs & Wires | 1.21.1-beta-0.2.3-C6 |
| Sable | 2.0.6 |
| Create Electro Energetics | 1.21.1-1.1.4 |
| DragonLib | 3.0.29 |

## Use

Use a CEE spool to connect the power supply to a P&W connector or cantilever terminal. Build an overhead supply with P&W feeders and contact wires, then complete the circuit through the collector, onboard load and return connection. Apply redstone to raise the collector. If registered to a cab, close its VCB.

A raised collector needs an energized wire and a complete circuit to deliver power. Current depends on the actual electrical load. An insulator interrupts continuity at its position; other supplies or bypass connections can still energize the other side.

Configuration: `config/pwsablefix-common.toml`.

# P&W Sable Fix 1.5.2

**让接触网真正为你的物理列车供电。**

面向 **Minecraft 1.21.1 NeoForge** 的铁路电气兼容附属，连接 Pantographs & Wires、Sable 与 Create Electro Energetics。

## 功能

- P&W 与原生 CEE 受电弓：有红石信号升弓，无信号降弓。
- Sable 移动物理结构上的 P&W 受电弓，可从 P&W 或 CEE 接触网取电。
- P&W 接触线、馈线接入 CEE 电路仿真，向车载负载供电。
- 多腕臂横排独立端子，支持分别供电；线缆绝缘子支持分段隔离。
- 接触、脱离带电线网时播放不同长度的电弧声，音源随车移动。
- 搭配 EMU Cab，支持受电弓登记、VCB 控制和实际网压、网流显示。

## 安装与依赖

客户端、服务端均安装 `pwsablefix-1.5.2.jar`，替换旧版附属。需要 Java 21。

| 组件 | 已验证版本 |
| --- | --- |
| Minecraft | 1.21.1 |
| NeoForge | 21.1.242 |
| Create | 6.0.10 |
| Pantographs & Wires | 1.21.1-beta-0.2.3-C6 |
| Sable | 2.0.6 |
| Create Electro Energetics | 1.21.1-1.1.4 |
| DragonLib | 3.0.29 |

## 使用

用 CEE 线轴连接电源与 P&W 接线器或腕臂端子，再用 P&W 馈线、接触线构成供电线路。受电弓、车载负载与回流线路须组成闭合回路。施加红石信号后升弓接触带电导线；已登记到驾驶台的受电弓需合上 VCB。

升弓不保证取电，网流取决于真实负载。绝缘子只切断该处连续导电，独立电源或旁路仍可能使另一侧带电。

配置：`config/pwsablefix-common.toml`。
